# VK Game Bot — экономическая RPG

Игровой бот для сообщества ВКонтакте на Python, Flask и SQLite с использованием VK Callback API.

## Возможности

- **Профиль** — баланс, дата регистрации, клан и число предметов.
- **Топ игроков** — рейтинг по количеству монет.
- **Ежедневная награда** — монеты раз в 24 часа.
- **Магазин и инвентарь** — покупка предметов за игровые монеты.
- **Кланы** — создание за 1000 монет, вступление по ID, список кланов и участников.
- **SQLite** — данные хранятся локально в `game.sqlite3`.
- Проверка секретного ключа Callback API и дедупликация событий по `event_id`.
- Токены берутся из переменных окружения; секреты не нужны в коде.

## Требования

- Python 3.11 или новее
- Сообщество VK, где включены сообщения
- Публичный HTTPS-адрес для Callback API (например, ваш сервер или туннель для теста)

## Запуск локально

1. Скачайте/клонируйте репозиторий.
2. Создайте окружение и установите зависимости:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Создайте `.env` на основе `.env.example` и заполните значения:

   ```bash
   cp .env.example .env
   ```

   В Windows можно просто скопировать файл вручную. Не публикуйте `.env` и не отправляйте токен в чат.

4. Запустите сервер:

   ```bash
   python bot.py
   ```

   При первом запуске автоматически создаётся база `game.sqlite3`. Проверка доступности: `http://localhost:8080/health`.

## Настройка VK Callback API

1. Откройте управление своим сообществом VK.
2. Включите **Сообщения сообщества**.
3. Перейдите в **Работа с API → Ключи доступа** и создайте ключ с правом отправки сообщений. Вставьте его в `VK_TOKEN`.
4. В **Работа с API → Callback API** добавьте сервер.
5. Укажите публичный HTTPS URL, заканчивающийся на `/vk`, например `https://your-domain.example/vk`.
6. Скопируйте код подтверждения сервера в `VK_CONFIRMATION_TOKEN`.
7. Если включён секретный ключ, укажите его в `VK_SECRET_KEY`. Если не используете секретный ключ, оставьте значение пустым.
8. В настройках Callback API включите событие **Входящее сообщение**.
9. Убедитесь, что `VK_GROUP_ID` — ID вашего сообщества без знака минус.
10. Нажмите «Подтвердить» в настройках сервера. VK должен получить строку подтверждения.

Для локального теста сервер должен быть доступен VK через публичный HTTPS-туннель. Не используйте обычный `localhost` как Callback URL.

## Команды в сообщениях сообщества

| Команда | Что делает |
|---|---|
| `помощь` | Список команд |
| `профиль` | Профиль и баланс |
| `топ` | Топ-10 по монетам |
| `ежедневно` | Ежедневная награда |
| `магазин` | Каталог предметов |
| `купить 1` | Купить предмет с ID 1 |
| `инвентарь` | Купленные предметы |
| `клан` | Информация о своём клане |
| `клан создать Драконы` | Создать клан (1000 монет) |
| `клан список` | Показать открытые кланы |
| `клан вступить 1` | Вступить в клан с ID 1 |
| `клан участники` | Показать участников своего клана |

Новый игрок начинает со 100 монет. Значение ежедневной награды можно изменить через `DAILY_REWARD`.

## Docker

```bash
docker build -t vk-game-bot .
docker run --env-file .env -p 8080:8080 -v "$PWD/data:/data" \
  -e DATABASE_PATH=/data/game.sqlite3 vk-game-bot
```

Для постоянного хранения SQLite подключайте постоянный volume. В production используйте HTTPS reverse proxy, настройте резервные копии базы и не запускайте несколько экземпляров с одной SQLite-базой без дополнительной координации.

## Важно

- Никогда не коммитьте `.env` или токен VK.
- Для публичного сервера используйте HTTPS.
- В обработчике Callback API предусмотрена проверка `group_id` и секретного ключа (если он задан).
- `processed_events` предотвращает повторную обработку уже полученных `event_id`.
- Это базовая версия экономической RPG; в ней пока нет административной панели, торговли между игроками или выхода из клана через команды.
